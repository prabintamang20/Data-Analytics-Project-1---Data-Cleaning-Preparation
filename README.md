Overview

This project focuses on cleaning and preparing a raw dataset using Microsoft Excel. Data cleaning is a critical step in the analytics process because accurate insights depend on high-quality data.

Goal

To clean a raw dataset by handling missing values, removing duplicates, and correcting incorrect data formats.

Tasks Performed
Identified and handled missing values
Removed duplicate records
Corrected date, text, and number formats
Organized data for further analysis
Tools Used
Microsoft Excel
Skills Gained
Data Cleaning
Data Preparation
Data Quality Management
Excel Fundamentals
Outcome

Successfully transformed a raw dataset into a clean and reliable dataset ready for analysis.
